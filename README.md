# TruthLens AI 🔎

### Explainable AI-Based Fake News Detection System

TruthLens AI is a Python-based web application project that explores how machine learning can help analyze news articles and how Explainable AI can make model predictions easier to understand.

## 🎯 Project Objective

The goal is to build an interactive application that analyzes news content and explains the factors influencing a model's prediction.

## ✨ Planned Features

- News headline and article input
- Machine-learning-based fake news classification
- LIME-based explanations for individual predictions
- A simple and user-friendly Streamlit interface
- Educational information about responsible AI use

> Note: Classification and LIME explanations require the trained model and explainer to be integrated. AI predictions should not be treated as definitive proof that a news story is true or false.

## 🛠️ Technologies

- Python
- Streamlit
- Machine Learning
- Natural Language Processing (NLP)
- LIME (Local Interpretable Model-agnostic Explanations)

## 🚀 Getting Started

### 1. Install Python

Install Python on your computer if it is not already installed.

### 2. Download the project

Clone this repository or download it as a ZIP file from GitHub.

### 3. Open the project folder

Open a terminal in the folder containing the application file.

### 4. Install Streamlit

```bash
pip install streamlit
```

### 5. Run the application

```bash
python -m streamlit run truthlens_expanded.py
```

If your main application file has a different name, replace `truthlens_expanded.py` with that filename.

## ⚠️ Limitations

The quality of predictions will depend on the training data and model performance. News should be checked against reliable sources. The application is an educational project, not a replacement for fact-checking.
